Decision records — append-only, hash chained

Each record's record_hash is sha256(prev_hash + canonical_json(record)), so the linked hashes below form a tamper-evident chain: altering any record invalidates every hash after it. Records are never updated or deleted — corrections are new records that reference the original. Entity types are recorded; values never are.
